# CHANGELOG

## Version History

Release headings version the repository; the collector carries its own `scriptVersion`, named in each `mongooseCollect.zsh` bullet.

### 0.0.2 (14-Nov-2026)

- Add a fictional sample report, `examples/mongoose-sample-report.md`
- Skill: MDM health summary (`references/mdm-health/`) that rolls up finished endpoint reports for one client's MDM from a manifest: validated generic aliases, sanitized MDM and Notes text, one client per run, report paths confined to the report directory, manifest and report hashes before reading, report time from each report's named collection source, default seven-day periods, prevalence from each endpoint's newest report with a stated rule for which endpoints could observe each category, and trend statuses over endpoints sampled in both periods only; never across clients or MDMs, never writes serials, and asks no redaction question (issue #2)
- Report: the Captures table states each collection or snapshot time with its offset
- Add a fictional sample MDM health summary, `examples/mongoose-sample-mdm-health.md`
- CONTRIBUTING: minimum inputs to add another MDM
- Skill: read organization script logs from a per-script log directory the Mac Admin names (`<script-log-dir>`), as well as from `<rdnn>.log`, and state that Mongoose runs off the Mac on any collected client-log bundle, including nested folders (issue #4)
- `mongooseCollect.zsh` 0.0.2: add Parameter 8, a per-script log directory collected recursively (plain `*.log` files and their rotated siblings; symlinks and hidden directories skipped; `/` refused; 500-file cap on `*.log` and rotated files combined; never written, so a Parameter 4 log inside it is not appended to and an output directory inside it is refused), with flattened member names and manifest lines for the directory and the files discovered (issue #4). A rejected Parameter 8 no longer marks the bundle incomplete when Parameter 4 yields a log, and rotated siblings of every log are limited to `<log>.<n>`, `<log>.<n>.gz` and `<log>.<n>.bz2`
- `mongooseCollect.zsh` 0.0.3: Parameter 5 accepts a Unified Logging predicate as well as a file path, exported with `log show` over the Parameter 7 window as the required MDM agent log (`*-mdm-agent.log`; an export with no entries is recorded as missing). Left empty, it detects the MDM vendor from the enrollment profile without recording the server address: Jamf Pro and undetected Macs use `/var/log/jamf.log`. Jamf School is matched before Jamf Pro and Fleet only on `fleetdm`; a recognized vendor with no known agent log source collects `/var/log/jamf.log` when it exists (with a warning and a manifest note) and is otherwise recorded as missing. Parameter 5 is trimmed of leading and trailing whitespace, file paths must be absolute, and a relative-looking value with no predicate operator is rejected without being echoed. Parameter 7 becomes the Unified Logging window for both exports, and the manifest names the detected vendor and the agent log source; a Unified Logging export's manifest `source` shell-quotes the predicate, so it pastes back as a working command. Skill: the Script-Deployment Playbooks template names `*-mdm-agent.log` as an alternative MDM agent log member (issue #5)
- Skill: preliminary audits accept an inventory CSV or a list-shaped JSON as well as one JSON record (`references/inventory-exports.md`): select one Mac by the serial named, cite CSV cells by data row and column as exported, parse CSV with in-memory `sqlite3` keeping every cell as text, and read an optional sanitized console history excerpt as server-reported status only. Mosyle `/devices` JSON and console CSV are accepted with fields found by search, and its Commands Activity Log gap is named under Limitations (issue #6)
- `mongooseCollect.zsh` 0.0.4: after a successful run, print paste-ready lines (real archive path, `sudo cp`, `sudo chown "$USER"`, `chmod 600`) that give the logged-in user a readable copy in `~/Downloads`, a folder iCloud Drive does not sync, with the sensitive-data warning kept; README adds the Claude desktop app (chat) path (issue #7)
- `mongooseCollect.zsh` 0.0.5: the handoff becomes one paste-ready line, `( umask 077; sudo cat <archive> > ~/Downloads/<name> )`, so root only reads the archive and never writes into the user's directory; the redirection runs as the pasting user, a link planted at the destination gains nothing, and the copy is user-owned with mode `600`. The line runs `sudo`, so the pasting user must be an administrator, and the console says so; README covers a standard user and an MDM policy run, where the line lands in the policy log. Parameter 8 discovery skips paths holding control characters, which would break the manifest's tab-separated rows and split log lines, and counts them without echoing them. Parameters 4, 5 (file path or predicate), 6 and 8 are rejected when they hold control characters, without echoing the value; Parameter 6 stops the script before staging. Parameter 7 is accepted only from `1m` to `30d`. Docs: Parameter 8 should name only a script-log directory, never a broad one such as `/Users` or `/Library`
- Known limitations: `mongooseCollect.zsh` MDM vendor detection (Parameter 5 empty) is verified only on a Jamf Pro-enrolled Mac; other vendors are untested
